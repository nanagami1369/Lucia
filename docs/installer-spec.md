# インストーラー仕様書

## 目的

OSネイティブに統合されたUX体験を提供する。
具体的には「設定アプリのアプリ一覧に表示され、そこからアンインストール・変更（リペア）できる」こと。

---

## 設定パラメータ

インストール時にユーザーが指定する。

| パラメータ | デフォルト | 用途 |
|---|---|---|
| インストール先 | `C:\Program Files\Lucia\` | ファイル配置先・サービス起動パス |
| PORT | `6100` | サービス起動引数・FWルールのポート番号 |
| ALLOWED_SUBNET | `192.168.0.0/16` | FWルールの接続元IP制限（CIDR形式） |

### バリデーションルール

| パラメータ | ルール |
|---|---|
| インストール先 | 有効なWindowsパス・書き込み可能であること |
| PORT | 1〜65535 の整数 |
| ALLOWED_SUBNET | IPv4 CIDR 形式（例: `192.168.0.0/16`） |

---

## コマンドラインインターフェース

`Lucia.Installer.exe` は純粋な CLI アプリケーション（コンソールアプリ）。ConsoleAppFramework v5 を使用したサブコマンド方式。

### 書式

```
Lucia.Installer.exe                            インストール状態を表示（引数なし）
Lucia.Installer.exe install   [オプション]     インストール
Lucia.Installer.exe uninstall [オプション]     アンインストール
Lucia.Installer.exe modify    [オプション]     設定変更（ポート・サブネット）
Lucia.Installer.exe status                     インストール状態を表示
Lucia.Installer.exe --help                     ヘルプを表示
```

### install オプション

| オプション | デフォルト | 説明 |
|---|---|---|
| `--install-dir <パス>` | `C:\Program Files\Lucia\` | インストール先 |
| `--port <番号>` | `6100` | サービスのポート番号 |
| `--subnet <CIDR>` | `192.168.0.0/16` | FWルールの接続元IP制限 |
| `--yes` | — | 確認プロンプトをスキップ |

### uninstall オプション

| オプション | デフォルト | 説明 |
|---|---|---|
| `--yes` | — | 確認プロンプトをスキップ |

### modify オプション

| オプション | デフォルト | 説明 |
|---|---|---|
| `--port <番号>` | （現在値を維持） | 新しいポート番号 |
| `--subnet <CIDR>` | （現在値を維持） | 新しいサブネット |
| `--yes` | — | 確認プロンプトをスキップ |

### 終了コード

| コード | 意味 |
|---|---|
| `0` | 成功 |
| `1` | バリデーションエラー（不正な引数値・未インストールでのアンインストール等） |
| `2` | 処理失敗（権限不足・操作エラー等） |

### インストール済み判定

レジストリキー `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\Lucia\` の存在で判定する。

## ファイル配置

| 項目 | 値 |
|---|---|
| 配置先 | `[インストール先]`（デフォルト: `C:\Program Files\Lucia\`） |
| 配置ファイル | `Lucia.Server.exe` およびpublish出力の全ファイル |
| `Lucia.Installer.exe` | インストーラー自身をインストール先に配置（アンインストーラー兼用） |
| ビット幅 | 64-bit |

## インストール処理の順序とロールバック方針

### インストール手順

| 順序 | 処理 | 備考 |
|---|---|---|
| 1 | レジストリ書き込み | **最初に実行**。失敗時でも設定アプリから確認・リペア可能にするため |
| 2 | ファイル展開・`Lucia.Installer.exe` 配置 | リペア時のロック解除のためサービスを事前停止 |
| 3 | Windows Service 登録（既存なら `sc config` でリペア） | 他サービスを破壊しないよう削除せず上書き更新 |
| 4 | ファイアウォール規則（既存削除→再追加） | ポート・サブネット変更に対応 |
| 5 | イベントログソース登録（なければ作成） | — |

### ロールバック

インストール途中で失敗した場合、完了済みのステップを逆順でクリーンアップする。

## Windows Service

| 項目 | 値 |
|---|---|
| サービス名（内部） | `LuciaServer` |
| 表示名 | `Lucia Session Monitor` |
| 説明 | `Lucia Windows RDS ホスト管理ダッシュボード サービス` |
| 起動タイプ | 自動 |
| 実行ファイル | `[インストール先]Lucia.Server.exe` |
| 起動引数 | `--urls http://0.0.0.0:[PORT]`（デフォルト: `--urls http://0.0.0.0:6100`） |
| インストール時 | 既存なら `sc config` でリペア、なければ `sc create` → 開始 |
| アンインストール時 | 停止 → 削除 |

**ImagePath の設定**: `sc.exe` の引用符エスケープ問題を回避するため、`HKLM\SYSTEM\CurrentControlSet\Services\LuciaServer\ImagePath` をレジストリに直接書き込む。

---

## ファイアウォール規則

| 項目 | 値 |
|---|---|
| ルール名 | `LuciaServer` |
| プロトコル | TCP |
| ポート | `[PORT]`（デフォルト: `6100`） |
| プロファイル | プライベート |
| 接続元IP制限 | `[ALLOWED_SUBNET]`（デフォルト: `192.168.0.0/16`） |
| インストール時 | 既存削除 → 再追加 |
| アンインストール時 | 規則を削除 |

**`netsh` の `0.0.0.0/0` 制約**: `netsh advfirewall` は CIDR `0.0.0.0/0`（全許可）を解釈できない。`ALLOWED_SUBNET` が `0.0.0.0/0` の場合は `Any` に変換して渡す。

| 項目 | 値 |
|---|---|
| ログ名 | `Application` |

| インストール時 | 未登録の場合のみ作成 |

## レジストリ登録（設定アプリへの表示）

`HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\Lucia\` に以下を書き込む。

| 値名 | 型 | 内容 | 例 |
|---|---|---|---|
| `DisplayName` | REG_SZ | アプリ名 | `Lucia` |
| `DisplayVersion` | REG_SZ | バージョン文字列 | `1.0.0.0` |
| `Publisher` | REG_SZ | 発行元 | `nanagami1369` |
| `UninstallString` | REG_SZ | アンインストール実行コマンド | `"[インストール先]Lucia.Installer.exe" uninstall` |
| `ModifyPath` | REG_SZ | 設定変更起動コマンド（設定アプリの「変更」ボタン） | `"[インストール先]Lucia.Installer.exe" modify` |
| `InstallLocation` | REG_SZ | インストール先フォルダ | `[インストール先]` |
| `Port` | REG_DWORD | サービスのポート番号 | `6100` |
| `AllowedSubnet` | REG_SZ | FWルールのサブネット | `192.168.0.0/16` |
| `NoModify` | REG_DWORD | `0`（「変更」ボタンを表示） | `0` |
| `NoRepair` | REG_DWORD | `0`（「修復」ボタンを表示） | `0` |

`Port` と `AllowedSubnet` はリペア時に設定を復元するために保存する。

**書き込みタイミング:** インストール処理の**最初**に書き込む（失敗後でも設定アプリからリペア実行できるようにするため）。

**削除タイミング:** アンインストール処理でファイル削除の**前**に削除する（後述）。

## アンインストール自己コピー方式

`Lucia.Installer.exe` はインストール先に配置されアンインストーラーを兼ねるが、自身が実行中のためファイル・フォルダを直接削除できない。これを回避するため自己コピー方式を採用する。

### 動作フロー

1. `Lucia.Installer.exe uninstall` が起動される
2. 自身を `%TEMP%\lucia-uninstaller-<GUID>.exe` にコピーする
3. TEMPコピーを `uninstall --source "<インストール先>"` で起動する（stdout/stderr をリダイレクトして元プロセスのコンソールへ転送）
4. 元プロセスは TEMPコピーの終了を待機して exit code を転送する
5. TEMPコピーは `--source` の存在でTEMP実行と判断し、実際のアンインストール処理を実行する
6. TEMPコピー自身は `%TEMP%` に残るが、OSの定期クリーンアップに委ねる

**`--source` は内部フラグ**であり、ユーザーが直接指定する必要はない。

---

## アンインストール処理の順序

| 順序 | 処理 | 備考 |
|---|---|---|
| 1 | Windows Service を停止・削除 | — |
| 2 | ファイアウォール規則を削除 | — |
| 3 | イベントログソースを削除 | — |
| 4 | レジストリの Uninstall キーを削除 | **ファイル削除より先に実行**。後述のファイルロック問題に対応するため |
| 5 | `[インストール先]` フォルダを削除 | ロック時は `cmd.exe` 遅延削除にフォールバック（後述） |

### レジストリをファイルより先に削除する理由

自己アンインストール時、元プロセスが `Lucia.Installer.exe` をメモリマップしているため、TEMPコピーは `[インストール先]` フォルダを直接削除できない場合がある。その場合でもレジストリが先に削除済みであれば、設定アプリのインストール済み一覧から確実に消える。

### ファイル削除の cmd.exe フォールバック

直接削除が失敗した場合（ファイルロック等）、`cmd.exe /C timeout /t 3 /nobreak > nul & rd /s /q "[インストール先]"` を起動して終了する。元プロセス・TEMPコピーが終了してロックが解放された後（約3秒後）に `cmd.exe` がフォルダを削除する。

## 設定変更処理

設定アプリの「変更」ボタンまたは `Lucia.Installer.exe modify` で実行する。ファイルは一切触らない。

### 変更手順

| 順序 | 処理 |
|---|---|
| 1 | Windows Service を停止 |
| 2 | ファイアウォール規則を削除→新しいポート・サブネットで再追加 |
| 3 | サービスの ImagePath を新しいポートで更新（レジストリ直書き） |
| 4 | アンインストールキー（`Port`・`AllowedSubnet`）を更新 |
| 5 | Windows Service を起動 |

失敗した場合もロールバックは行わない。レジストリは Step 4 まで旧値を保つため、失敗後も `modify` コマンドから再実行できる。

---

## 権限要件

管理者権限が必要。`app.manifest` に `requestedExecutionLevel level="requireAdministrator"` を設定し、起動時に UAC プロンプトを表示する。
