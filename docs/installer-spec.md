# インストーラー仕様書

## 目的

OSネイティブに統合されたUX体験を提供する。
具体的には「設定アプリのアプリ一覧に表示され、そこからアンインストール・変更（リペア）できる」こと。

---

## 設定パラメータ

インストール時にユーザーが入力する。

| パラメータ | デフォルト | 用途 |
|---|---|---|
| インストール先 | `C:\Program Files\Lucia\` | ファイル配置先・サービス起動パス |
| PORT | `6100` | サービス起動引数・FWルールのポート番号 |
| ALLOWED_SUBNET | `192.168.0.0/16` | FWルールの接続元IP制限（CIDR形式） |

### バリデーションルール

| パラメータ | ルール |
|---|---|
| インストール先 | 有効なWindowsパス・書き込み可能であること |
| PORT | 1〜65535 の整数 |
| ALLOWED_SUBNET | IPv4 CIDR 形式（例: `192.168.0.0/16`） |

---

## 起動モード

引数の組み合わせによって動作が決まる。

### 優先順位と動作一覧

| 条件 | 動作 |
|---|---|
| `--help` | コンソールに使い方を出力して終了（コンソールなし時は MessageBox） |
| `--silent` あり | CLIモード（UI非表示）。他オプションと組み合わせて使用 |
| `--uninstall --source <dir>` | アンインストール進捗画面を表示して自動実行（TEMPコピーからの起動） |
| `--modify`（インストール済み） | 設定変更ウィザードを表示 |
| `--modify`（未インストール） | エラーダイアログを表示して終了 |
| `--uninstall`（インストール済み） | メニュー画面を表示 |
| `--uninstall`（未インストール） | エラーダイアログを表示して終了 |
| 引数なし（インストール済み） | メニュー画面を表示 |
| 引数なし（未インストール） | インストールウィザードを表示 |

**`--port` / `--subnet` / `--install-dir` は `--silent` と組み合わせた場合のみ有効。`--silent` なしで指定した場合は無視される。**

### インストール済み判定

レジストリキー `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\Lucia\` の存在で判定する。

---

## インストールUIフロー

```
ライセンス確認 → インストール先選択 → 設定入力（PORT / ALLOWED_SUBNET） → 確認 → インストール実行
```

---

## メニュー画面（インストール済み時）

インストール済みの状態で引数なし起動、または `--uninstall`（`--source` なし）で起動した場合に表示する。

- **変更**: 設定変更ウィザード（ポート・サブネット）へ遷移する
- **アンインストール**: 自己コピー方式でアンインストールを開始する（後述）
- **キャンセル**: 終了する

---

## CLIモード（--silent）

`--silent` を指定した場合のみ CLI モードで動作する。UI は一切表示しない。自動化・スクリプト組み込み用途を想定。

### 書式

```
installer.exe --silent [インストールオプション]
installer.exe --silent --uninstall
installer.exe --silent --modify [--port <番号>] [--subnet <CIDR>]
installer.exe --help
```

### オプション

| オプション | デフォルト | 説明 |
|---|---|---|
| `--silent` | — | CLIモードで動作する（必須） |
| `--install-dir <パス>` | `C:\Program Files\Lucia\` | インストール先（`--silent` 時のみ有効） |
| `--port <番号>` | `6100` | サービスのポート番号（インストール時: `--silent` 時のみ有効。変更時: 省略すると現在値を維持） |
| `--subnet <CIDR>` | `192.168.0.0/16` | FWルールの接続元IP制限（インストール時: `--silent` 時のみ有効。変更時: 省略すると現在値を維持） |
| `--uninstall` | — | アンインストールを実行する |
| `--modify` | — | 設定変更を実行する（ポート・サブネットを変更してサービスを再起動） |
| `--help` | — | 使い方を出力して終了（`--silent` 不要） |

### 終了コード

| コード | 意味 |
|---|---|
| `0` | 成功 |
| `1` | バリデーションエラー（不正な引数値・未インストールでのアンインストール等） |
| `2` | 処理失敗（権限不足・操作エラー等） |

### バリデーション

`--silent` 時はUIが存在しないため、不正な引数が渡された場合は即座に終了コード `1` で終了する。エラー内容は標準エラー出力に出力する。

`--silent --uninstall` で未インストール（レジストリなし）の場合も終了コード `1` で終了する。

## インストール処理の順序とロールバック方針

### インストール手順

| 順序 | 処理 | 備考 |
|---|---|---|
| 1 | レジストリ書き込み | **最初に実行**。失敗時でも設定アプリから確認・リペア可能にするため |
| 2 | ファイル展開・`installer.exe` 配置 | — |
| 3 | Windows Service 登録（既存なら `sc config` でリペア） | 他サービスを破壊しないよう削除せず上書き更新 |
| 4 | ファイアウォール規則（既存削除→再追加） | ポート・サブネット変更に対応 |
| 5 | イベントログソース登録（なければ作成） | — |

### ロールバック

インストール途中で失敗した場合、完了済みのステップを逆順でクリーンアップする。

| 項目 | 値 |
|---|---|
| サービス名（内部） | `LuciaServer` |
| 表示名 | `Lucia Session Monitor` |

| 起動タイプ | 自動 |
| 実行ファイル | `[インストール先]Lucia.Server.exe` |
| 起動引数 | `--urls http://0.0.0.0:[PORT]`（デフォルト: `--urls http://0.0.0.0:6100`） |

| アンインストール時 | 停止 → 削除 |

## レジストリ登録（設定アプリへの表示）

`HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\Lucia\` に以下を書き込む。

| 値名 | 型 | 内容 | 例 |
|---|---|---|---|
| `DisplayName` | REG_SZ | アプリ名 | `Lucia` |
| `DisplayVersion` | REG_SZ | バージョン文字列 | `1.0.0.0` |
| `Publisher` | REG_SZ | 発行元 | `nanagami1369` |
| `UninstallString` | REG_SZ | アンインストール実行コマンド | `"[インストール先]installer.exe" --uninstall` |
| `ModifyPath` | REG_SZ | 設定変更起動コマンド（設定アプリの「変更」ボタン） | `"[インストール先]installer.exe" --modify` |
| `InstallLocation` | REG_SZ | インストール先フォルダ | `[インストール先]` |
| `Port` | REG_DWORD | サービスのポート番号 | `6100` |
| `AllowedSubnet` | REG_SZ | FWルールのサブネット | `192.168.0.0/16` |
| `NoModify` | REG_DWORD | `0`（「変更」ボタンを表示） | `0` |
| `NoRepair` | REG_DWORD | `0`（「修復」ボタンを表示） | `0` |

`Port` と `AllowedSubnet` はリペア時に設定を復元するために保存する。

**書き込みタイミング:** インストール処理の**最初**に書き込む（失敗後でも設定アプリからリペア実行できるようにするため）。

**削除タイミング:** アンインストール処理の**最後**に削除する（途中失敗時でも設定アプリから再実行できるようにするため）。

## アンインストール自己コピー方式

`installer.exe` はインストール先に配置されアンインストーラーを兼ねるが、自身が実行中のためファイル・フォルダを直接削除できない。これを回避するため自己コピー方式を採用する。

### 動作フロー

1. `installer.exe --uninstall`（または `--silent --uninstall`）が起動される
2. 自身を `%TEMP%\lucia-uninstaller-<GUID>.exe` にコピーする
3. TEMPコピーを `--uninstall --source "<インストール先>"` で起動して元プロセスを終了する
4. TEMPコピーは `--source` の存在でTEMP実行と判断し、実際のアンインストール処理を実行する
5. アンインストール完了後、TEMPコピー自身は OS によって次回起動時に自動削除される

GUIモードでは手順3でTEMPコピーがアンインストール進捗画面を表示する。CLIモード（`--silent`）では進捗をコンソールに出力する。

**`--source` は内部フラグ**であり、ユーザーが直接指定する必要はない。

---

## アンインストール処理の順序

| 順序 | 処理 |
|---|---|
| 1 | Windows Service を停止・削除 |
| 2 | ファイアウォール規則を削除 |
| 3 | イベントログソースを削除 |
| 4 | `[インストール先]` フォルダを削除 |
| 5 | レジストリの Uninstall キーを削除（**最後に実行**） |

---

## 設定変更処理

設定アプリの「変更」ボタンまたは `installer.exe --modify` で実行する。ファイルは一切触らない。

### 変更手順

| 順序 | 処理 |
|---|---|
| 1 | Windows Service を停止 |
| 2 | ファイアウォール規則を削除→新しいポート・サブネットで再追加 |
| 3 | サービスの ImagePath を新しいポートで更新（レジストリ直書き） |
| 4 | アンインストールキー（`Port`・`AllowedSubnet`）を更新 |
| 5 | Windows Service を起動 |

失敗した場合もロールバックは行わない。レジストリは Step 4 まで旧値を保つため、失敗後も変更ウィザードから再実行できる。

---

## 権限要件

管理者権限が必要。インストーラー起動時にUACプロンプトを表示する。
